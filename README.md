# Тренажёр чтения нот

Браузерный тренажёр по образцу doremis.ru: на нотоносце появляется нота — вы нажимаете её
на цифровом пианино (MIDI). На компьютере ничего устанавливать не нужно; на телефоне
(Android) приложение ставится как PWA и работает офлайн.

## Запуск на компьютере

1. Откройте `index.html` в **Google Chrome**, Яндекс.Браузере или Edge
   (Firefox не поддерживает Web MIDI).
2. При первом запуске Chrome спросит разрешение «использовать MIDI-устройства» — разрешите.
3. В шапке выберите своё пианино (NUX NPK-200 подхватится автоматически).
4. Нажмите «Начать» и играйте.

С `file://` PWA-обвязка (манифест, service worker) просто игнорируется — это нормально.

## Установка на телефон (Android)

Web MIDI работает только в Chrome на Android (в Safari на iPhone его нет вообще) и требует
защищённого контекста — `https` или `localhost`. Поэтому установка делается один раз
по USB-кабелю, дальше приложение работает без компьютера — пианино подключается
прямо к телефону (USB-OTG):

1. На телефоне: Настройки → Сведения о телефоне → несколько раз нажмите «Номер сборки»
   (на MIUI — «Версия MIUI») → в «Для разработчиков» включите **Отладку по USB**.
   Подключите телефон к компьютеру.
2. На компьютере (из папки проекта) — одна команда:
   ```bash
   node phone.mjs
   ```
   Она сама: найдёт телефон, поднимет сервер, пробросит порт (`adb reverse`),
   откроет Chrome на телефоне и будет восстанавливать проброс при переподключении
   кабеля. Остановка — Ctrl+C.
3. На телефоне: разрешите доступ к MIDI-устройствам, дождитесь полной загрузки
   (service worker должен зарегистрироваться) и нажмите «Установить приложение»
   на странице или в меню Chrome (⋮).
4. Отключите кабель от компьютера и вставьте его в цифровое пианино (USB-OTG).
   Запускайте приложение с иконки — оно офлайн, пианино появится в шапке автоматически.

Обновление установленного приложения: подключить телефон к компьютеру, снова
`node phone.mjs` (или запасной путь ниже), открыть приложение/страницу и подождать
~5 с — новая версия кэша активируется (см. примечание про версию кэша ниже;
обновление доходит, только пока проброс жив).

Запасной вариант — вручную:

```bash
node serve.mjs                # поднимет http://localhost:8737
adb devices                   # телефон должен быть виден
adb reverse tcp:8737 tcp:8737 # пробрасывает порт на телефон
# на телефоне в Chrome: http://localhost:8737
```

### Если не работает

- **«Телефон не виден»** — кабель без передачи данных (зарядный), не включена
  «Отладка по USB», или на телефоне висит непринятый RSA-запрос «Разрешить отладку».
- **«Нет прав к USB-устройству»** — поставьте udev-правила:
  `sudo apt install android-sdk-platform-tools-common`, затем переподключите кабель.
- **adb не установлен** — `sudo apt install adb`.
- **Несколько телефонов** — `node phone.mjs --serial <id>` (список id печатается).
- **`error: closed` при пробросе** — телефон только что разблокирован, adbd
  поднимается; `phone.mjs` сам повторяет попытки.
- **Открылся не Chrome** (MIUI-браузер) — откройте `http://localhost:8737` в Chrome вручную.
- **Установленное приложение перестало запускаться офлайн** — Chrome снёс данные сайта
  при очистке/нехватке места; переустановите по кабелю (шаги выше).
- MIUI иногда сбрасывает «Отладку по USB» после перезагрузки — включите снова.

> **Почему не по Wi-Fi?** `http://<ip-компьютера>:8737` — не защищённый контекст,
> Chrome не даст доступ к MIDI и не установит PWA. Нужен именно `localhost` (через USB)
> или настоящий https. По Wi-Fi страница откроется, но играть можно будет только
> по экранным клавишам.

## Возможности

- **Режим «Ноты»**: верное нажатие — нота зеленеет и появляется следующая,
  неверное — считается ошибкой.
- **Режим «Аккорды»**: трезвучия — какие функции тренировать, решают чекбоксы
  «Тоника (I)», «Субдоминанта (IV)», «Доминанта (V)» в любых комбинациях
  (например, только тоника; снять последнюю нельзя). Зачёт блоком — все три клавиши
  зажаты одновременно; без подключённого MIDI аккорд можно набрать и по очереди,
  тапая клавиши по одной. Чекбокс «С обращениями»: тоника (основное положение),
  секстаккорд и квартсекстаккорд — все три положения доступны, даже если узкий
  диапазон вмещает не всё (форма добирается из более широкого окна).
  Тональность: все 24 случайно, только мажорные, только минорные или одна
  (селект); в миноре доминанта — мажорная, как в гармоническом миноре.
  Если узкий диапазон не вмещает основное положение, берётся вмещающееся обращение.
- Ключ: скрипический, басовый или оба (случайно); диапазон: в пределах линееек,
  с добавочными линейками, широкий — общая настройка для нот и аккордов.
- Белые клавиши или с диезами (для нот); показ названия (никогда / после ошибки / всегда).
- Статистика: верно, ошибки, точность, серия, рекорд серии, среднее время реакции, таймер.
- Виртуальная клавиатура внизу подсвечивает нажатия в реальном времени; работает мышью
  и мультитачем — на телефоне аккорды можно ставить несколькими пальцами.
- Опциональный синтез звука через устройство (по умолчанию выключен — пианино звучит само).
- На телефоне: экран не гаснет во время сессии (wake lock), установка как приложение (PWA),
  офлайн-работа.

## Устройство

- `index.html` — всё приложение (HTML + CSS + JS, без сборки и без ES-модулей,
  поэтому работает прямо с `file://`).
- `vendor/vexflow.js` — VexFlow 4.2.3 (отрисовка нотации), локальная копия — работает офлайн.
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA: манифест, service worker (офлайн-кэш),
  иконки. `make-icons.py` перегенерирует иконки (Pillow).
- `serve.mjs` — локальный сервер без зависимостей (`node serve.mjs`, порт 8737).
- `phone.mjs` — подключение телефона одной командой: сервер + `adb reverse` + Chrome
  на телефоне + автоспасение проброса при переподключении USB.
- Web MIDI API принимает события с пианино, Web Audio синтезирует звук, если включён.

**Примечание про кэш:** service worker отдаёт файлы из кэша. После изменения
`index.html` / `vendor` / манифеста поднимите версию `CACHE` в `sw.js` (`pt-v1` → `pt-v2`),
иначе установленное приложение продолжит показывать старую версию.

## Проверка (разработка)

```bash
python3 make-icons.py   # перегенерация иконок
node e2e-pwa.mjs        # сервер, манифест, service worker, офлайн, file://-регрессия
node e2e-mobile.mjs     # эмуляция телефона: тап по клавише, аккорд тремя пальцами,
                        # адаптивность клавиатуры (без скролла, клавиши ≥ 28px)
node serve.mjs          # + node e2e-midi.mjs — проверка железа с настоящим пианино
node phone.mjs          # живой телефон: сервер + проброс + Chrome (Ctrl+C — стоп)
```

## Проверка без пианино

В консоли браузера:

```js
__trainer.start()            // начать сессию
__trainer.state()            // текущая цель (нота или аккорд) и статистика
__trainer.press(60)          // «нажать» MIDI-ноту 60 (до C4)
__trainer.release(60)        // «отпустить» — нужно для аккордов блоком
```
